总览

返回主页 →

这是把 Uma Musume: Pretty Derby 的 master.mdb 与 meta（游戏加密数据库，导入前自动解密）整体导入 MariaDB 后， 由 ASP.NET Core 生成的只读 REST 接口。

每个游戏数据表对应一个端点，例如 /api/TextData、 /api/SkillData、/api/MetaA； 全部端点、参数和返回结构见 接口文档，也可直接取 OpenAPI JSON 自己生成客户端。

接口只做透传，不含游戏内玩法逻辑；跨域已放开，可直接从网页调用。 数据与素材版权归 Cygames 所有。
