这是一个基于《赛马娘 Pretty Derby》（Uma Musume: Pretty Derby）的 master.mdb 与 meta 文件构建的社区 REST API， 数据存储在 MariaDB 数据库中。该项目遵循 Swagger UI/OpenAPI 规范。

每个游戏数据表对应一个端点，例如 /api/TextData、 /api/SkillData、/api/MetaA； 全部端点、参数和返回结构见 接口文档，也可直接取 OpenAPI JSON 自己生成客户端。

功能特性
该 API 不仅提供了直接访问数据表的接口（endpoints），我还针对常用数据表创建了包含基础信息的视图（views）。此外，我还实现了一些存储过程（stored procedures），用于处理特定的计算逻辑，例如“因子继承相关性”及“推荐组合”计算。

API 的整体结构如下：
原始数据（直接从 meta 和 master.mdb 文件导入）
常用表的基础索引（接口名称以 'Basic' 为前缀）
包含外键关联的精简数据，便于生成报表（接口名称以 'Condensed' 为前缀）
经过整理、更易于阅读的常用信息（接口名称以 'Nice' 为前缀）
存储过程（接口名称以 'Sp' 为前缀）
